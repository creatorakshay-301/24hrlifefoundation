24 HR LIFE FOUNDATION — PREMIUM FRONTEND (VS CODE)

WHAT'S INCLUDED
- index.html: premium homepage
- about.html: foundation profile, purpose and leadership
- our-work.html: Education, Health, Environment and Social Work
- projects.html: initiative themes with clear planning-status labels (no invented impact claims)
- donate.html: donation enquiry interface with amount selector; no payment processing is enabled
- volunteer.html: validated volunteer enquiry form that opens WhatsApp with a prefilled message
- contact.html: contact details and enquiry form that opens WhatsApp
- css/style.css: responsive styling
- js/main.js: navigation, language persistence, donation amount selector and enquiry form behaviour
- js/translations.js: English, Hindi and Marathi homepage translations
- assets/foundation-logo.png: supplied foundation logo

RUN IN VS CODE
1. Open this project folder in VS Code.
2. Install the Live Server extension if it is not already installed.
3. Right-click index.html > Open with Live Server.
4. Test all menu links, language selector, donate amount buttons and enquiry forms.

IMPORTANT DONATION / LEGAL NOTES
- The Donate page is an enquiry-only frontend. It does NOT collect payments or store donor details.
- Do not add UPI IDs, bank details, payment gateway or tax-benefit claims until the Trust verifies its official payment account and all applicable approvals / registrations.
- No 80G, CSR-1 or FCRA claim is made in this starter.
- Add the official email, exact registered office address and trust registration number after verification.
- Project cards are labelled as planning themes. Replace them with real, approved activities and verified outcomes only.

GITHUB + NETLIFY
- Upload the complete folder to a GitHub repository, preserving the css, js and assets folders.
- In Netlify, import the repository from GitHub.
- Build command: leave blank.
- Publish directory: .
- Deploy. Netlify will provide a public URL.

This is a static frontend. A backend (database, admin dashboard, secure payments, email delivery and file uploads) is not included yet and should be added in a later phase.
